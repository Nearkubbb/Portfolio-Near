# 🌸 KruTech E-Portfolio

เว็บไซต์แฟ้มสะสมผลงานออนไลน์ (E-Portfolio) สำหรับครูผู้สอนด้านเทคโนโลยีและการเขียนโปรแกรม ออกแบบในธีมสีชมพู-ขาว ทันสมัย อ่านง่าย และรองรับการแสดงผลทุกขนาดหน้าจอ (Responsive Design)

🔗 **Live Demo:** `https://<username>.github.io/<repository-name>/` *(แก้ไขเป็นลิงก์ GitHub Pages ของคุณ)*

---

## ✨ คุณสมบัติหลัก (Features)

- **Single-File Architecture:** พัฒนาทั้งหมดในไฟล์ `index.html` เพียงไฟล์เดียว ไม่ต้องติดตั้ง Framework หรือ Build Tools เพิ่มเติม
- **โครงสร้างครบ 4 ส่วนหลัก:**
  1. **หน้าแรก (Hero Section):** แนะนำตัวตน แนวคิดการสอน และปุ่มลิงก์ไปยัง GitHub
  2. **แนะนำตัว (About Me):** ประวัติการศึกษา ตำแหน่ง ทักษะด้านเทคโนโลยี และปรัชญาการจัดการเรียนรู้
  3. **ผลงาน (Portfolio):** การ์ดแสดงผลงานการสอนและซอฟต์แวร์ พร้อมระบบกรองหมวดหมู่ (Filter) และลิงก์ซอร์สโค้ด
  4. **กิจกรรม (Activities):** ไทม์ไลน์แสดงผลงานการฝึกสอน การเป็นวิทยากร และการพัฒนาตนเอง
- **Responsive Navigation:** เมนูนำทางพร้อม Hamburger Menu สำหรับหน้าจอโทรศัพท์มือถือ และระบบ Highlight เมนูอัตโนมัติตามตำแหน่งการเลื่อนหน้าจอ
- **Thai Typography:** ใช้ฟอนต์ **Prompt** จาก Google Fonts เพื่อการอ่านภาษาไทยที่สวยงามและสบายตา

---

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)

- **HTML5** — โครงสร้างเว็บไซต์เชิงความหมาย (Semantic HTML)
- **CSS3** — จัดรูปแบบด้วย Flexbox, CSS Grid, CSS Variables และ Media Queries
- **JavaScript (Vanilla JS)** — จัดการเมนูมือถือ, Scroll Spy และระบบกรองหมวดหมู่ผลงาน
- **Google Fonts (Prompt)** & **Font Awesome 6** — ฟอนต์และไอคอนประกอบเว็บไซต์
